# 📘 Thesis Research Repository – AI-Driven Evaluation of UN SDG Claims

This repository contains the full research implementation for the thesis:

**“Quantifying the Social Impact of Carbon Credit Projects and Verifying UN SDG Claims Using GenAI”**

Developed as part of a Master’s by Research at the University of Technology Sydney, this project uses statistical modeling, prompt engineering, and generative AI to automate ESG evaluation processes.
